# Emotion Classification using NLP

Project UAS Data Mining

Implementasi klasifikasi emosi pada teks menggunakan Natural Language Processing (NLP) dan Logistic Regression.

## Dataset

Emotion Dataset for NLP

Label:

- joy
- sadness
- anger
- fear
- love
- surprise

## Technology

- Python
- Flask
- NLTK
- TF-IDF
- Logistic Regression
- HTML
- CSS
- Bootstrap

## Cara Menjalankan

Install library

pip install -r requirements.txt

Training model

python model/train_model.py

Menjalankan website

python app.py
